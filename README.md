# skills

Agent skills by 20Vision.

| Skill | What it does |
|---|---|
| wcag-audit | Check a web page against WCAG 2.2 and get the failures by success criterion with a fix for each. |
| house-plans | Find a ready-made house plan and download it free as PDF, DXF or IFC. |
| floor-plan-cad | Turn a brief or a sketch into a measured floor plan as a CAD drawing (DXF, DWG, PDF). |
| cloud-computer-task | Hand a long web task to your own cloud computer and get the result back. |
| scan-job-boards | Scan several job boards for new postings that match a search and list title, company, location and link. |
| find-funding-calls | Find open grants and funding calls a company qualifies for and build a spreadsheet sorted by deadline. |
| extract-numbers-from-pdf | Download PDF reports (annual reports, filings) and put the figures into a spreadsheet with the page number for each figure. |
| find-flats-and-fill-forms | Search rental portals for flats, pick the best listings and fill in the contact forms without sending them. |
| book-appointment-online | Find providers with online booking and a free slot, fill in the booking form and stop before confirming. |
| request-supplier-quotes | Write to suppliers from the computer's own email address, ask each for a quote and show every mail sent. |
| summarize-competitor-pricing | Open competitors' live pricing pages and write a one-page comparison of tiers, inclusions and limits. |
| find-conference-cfp-deadlines | Work through event listings and conference sites and build a spreadsheet of conferences with dates and call-for-papers deadlines, sorted by deadline. |
| build-lead-list | Find companies, open each site and read the imprint for the real contact address, filling a spreadsheet. |
| tiny-house-plans | Find free tiny house plans under about 600 sq ft and download PDF, DXF or IFC. |
| cabin-plans | Find free cabin floor plans and download PDF, DXF or IFC. |
| adu-plans | Find free ADU plans (backyard studios, 1 and 2 bedroom) and download PDF, DXF or IFC. |
| fund-open-source-task | Pick a task a maintainer asked for on MyClawn Fund and prepare the pull request for you to send. |
| csv-cleanup-to-clean-file | Clean a CSV file (duplicate rows removed by email, names capitalised) and get the cleaned file back by email. |
| product-listings-to-spreadsheet | Read every product in a store category page by page and get a spreadsheet of name, price, link and stock status. |
| product-reviews-summary | Read recent reviews of a product on several sites and get a short summary of praise and complaints, each with its source link. |
| seo-audit-to-fix-list | Audit the pages of a website and get a spreadsheet with title, description, H1, broken links and what to fix for each page. |
| broken-link-checker | Click through a website in a real browser and get a list of every link that errors or shows an empty page, with the page it is on. |
| web-app-browser-test-report | Go through a web app's flow in a real browser like a new user and get a numbered report of every step that fails or looks wrong. |
| youtube-videos-to-notes | Turn YouTube videos into notes with key points and timestamps, read from each video's transcript. |
| market-research-to-one-page-brief | Research a market from public sources and get a one-page brief with a link after every claim and a list of what was not found. |
| product-price-change-tracker | Save the prices and stock status of products you watch and, on the next run, get a list of what went up or down. |
| company-contact-email-finder | Find the published contact email for each company on a list and get a spreadsheet with the page each address came from. |
| supplier-invoices-to-spreadsheet | Download the invoices of a period from a supplier portal and get a sheet of date, number, amount and file name with the total. |
| spreadsheet-rows-to-web-form | Fill in a web form once for every row of a spreadsheet, stopping before submit so the first row can be checked. |
| web-page-change-checker | Save the wording of a web page and, on the next run, get the exact differences. |
| company-news-brief | Find the last seven days of news about a company or topic and get a brief of the ten most relevant items with date and link, mailed to you. |
| public-tender-finder | Search public procurement portals for open tenders in your trade and get a spreadsheet of title, buyer, deadline, value and link sorted by deadline. |
| podcast-guest-finder | Find active podcasts on a topic and get a spreadsheet with the latest episode date, contact or pitch page and whether the page mentions guests. |
| local-business-list-from-maps | Search a map for a type of business in an area and get a spreadsheet of name, address, phone, website and rating. |
| business-listing-checker | Check a business's listing on several directories against the correct details and get a table of what differs and where no listing exists. |
| company-meeting-briefing | Read a company's site, news and public profiles and get a one-page briefing with every fact linked and three questions to ask. |
| used-item-deal-finder | Search several marketplaces for a used item within your price and area and get the best five listings with price, condition, location and link. |
