# skills

Agent skills by 20Vision.

| Skill | What it does |
|---|---|
| wcag-audit | Check a web page against WCAG 2.2 and get the failures by success criterion with a fix for each. |
| house-plans | Find a ready-made house plan and download it free as PDF, DXF or IFC. |
| floor-plan-cad | Turn a brief or a sketch into a measured floor plan as a CAD drawing (DXF, DWG, PDF). |
| cloud-computer-task | Hand a long web task to your own cloud computer and get the result back. |

Install: `npx skills add 20vision/skills`
